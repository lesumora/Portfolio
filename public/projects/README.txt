Project media goes here.

Screenshots: add them to the project's `images` list in src/data/site.ts.
Export as .webp (or .png), about 1600px wide, and a 640px-wide copy for `thumb`.
The card keeps a fixed-size preview, so any number of images is fine.

Video: set `video` (and `poster`) on the project. Keep MP4 files under about 5 MB.
